# Leos Last Chance

Interaktiver Lernatlas mit Flashcards und Quiz für die Zwischenprüfungen der Polizei Sachsen (Eingriffsrecht, Kriminalistik, Verkehrsrecht).

- Einzeldatei `index.html` (Vanilla JS, keine Abhängigkeiten), Daten in `src/data/*.js`
- Build: `node build.js` → `dist/index.html`
- Fortschritt nur mit Einwilligung in einem Cookie (`llc`), kein Tracking
- Live: https://leos-last-chance.netlify.app

Hinweis: Kein offizielles Lernmaterial. Inhalte vor der Prüfung mit aktuellem Gesetzestext und Ausbildungsplan abgleichen.
